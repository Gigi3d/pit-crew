Daytona

The garage.

<90msTO BUILD A BAY
How: thirty sandboxes in parallel, each with its own kernel, filesystem, and network. Untrusted patches need that boundary to be safe, and benchmarks need it to be trustworthy. One primitive solves both.
no garage, no race
07
CodeRabbit

Scrutineering.

How: the winning patch opens as a real pull request, and CodeRabbit reviews it before it can merge. A benchmark proves the code is fast. It cannot tell you the code is unreadable.
the last gate before the branch
08
Fireworks AI

The power unit.

How: thirty patches means thirty inference calls per pull request. High-throughput open models make that a rounding error instead of a budget meeting. Throughput is what makes the swarm possible at all.
thirty engines, one stop
09
Braintrust

Telemetry.

How: every bay is logged and scored: which strategy, what ratio, legal or disqualified, at what token cost. We learn which optimisations win on which shape of code, so the next race starts smarter.
thirty data points per pull request
10
CopilotKit+ElevenLabs

Talk to the pit wall.

YOU, OVER RADIO“Box, box. Kill everything slower than three hundred milliseconds.”
CREW, 1.2s LATER“Copy. Twenty two bays retired. Eight still running. Fastest is bay twelve.”

CopilotKit

Turns the sentence into a real call on the swarm. A useCopilotAction handler kills, spawns, and re-seeds bays. The grid culls while you are still speaking.

ElevenLabs

Your voice in, the crew's voice back. Speech to text drives the command, and the confirmation comes back over team radio. Two way, not narration.

both of them change the race, neither just watches it

Safe by construction

Thirty untrusted agents.
Zero blast radius.

ISOLATED

Every patch runs in a Daytona sandbox with its own kernel and network. Nothing touches your machine.

HUMAN GATED

The output is a proposed pull request. Nothing reaches a branch without you approving it.

NO SELF-GRADING

The guard rejects any patch that edits the tests or the benchmark. The agent cannot move its own goalposts.

And the winning number is re-measured in a clean room that never ran the agent.
